# 📈 炒股达人

纯前端小游戏：选一只股票，模拟炒股 60~90 秒，体验被庄家诱多、诱空、反复收割的刺激人生。

## 玩法

1. 输入姓名，**选择股票**：
   - 🎯 **SNK-格力士**（新手）：60 秒，游资庄股，快节奏收割
   - 🐉 **大米科技**（硬核）：90 秒，事件驱动妖股，隐藏剧本 + 事件卡 + 涨跌停
2. 右侧 K 线图随时间自动涨跌
3. 期间可操作：**买 10 股 / 卖 10 股 / 全仓 / 清仓**
4. 时间结束弹窗结算：收益 + 收益率 + 趣味称号
5. 「上传成绩」保存到本地排行榜，「再来一局」重开

## 庄家逻辑（核心机制）

### SNK-格力士：游资庄股

K 线涨跌不是随机游走，而是由「庄家状态机」驱动：

| 玩家行为 | 庄家反应 |
| --- | --- |
| 小仓买入 | 拉升诱多（目标 +20%），到点出货砸盘 |
| 全仓买入 | 立刻砸盘收割 |
| 拉升中卖出 | 洗盘抖一下继续拉（让你踏空） |
| 下跌中割肉 | 再小跌一下然后反弹（割在地板上） |
| 反弹中追买 | 继续跌（套牢陷阱） |
| 拉到 +20% | 自动转砸盘出货 |

状态机：`normal 震荡 → pump 拉升 → dump 砸盘 → rebound 反弹 → …`，价格由每步 drift + 正态噪声驱动，每秒生成 1 根 K 线（内部 12 子步 + 随机影线）。

### 大米科技：事件驱动妖股

三个新机制，难度明显更高：

1. **隐藏剧本系统**：开局随机抽一个剧本（吸筹·拉升·出货 / 横盘·连板·天地板 / 洗盘拉锯），整局按剧本推进。玩家买卖**只产生 20~30% 扰动**，没有“卖了就涨、买了就跌”的机械规律，只能靠盘感。
2. **事件卡系统**：局中随机触发 2~4 个新闻事件（真假掺杂），通过**新闻栏滚动快讯** + **K 线图事件标记**展示，不弹窗不打断操作。利好、利空、模棱两可、出货掩护（利好冲高就砸）……练的是“利好不追、利空不慌”。
3. **涨跌停机制**：由重磅事件卡触发——被收购 → **涨停封板买不进**；高层卷入案件 / 被外国针对 → **跌停封板卖不出**。封板数根 K 线后开板，流动性风险拉满。每局最多一个重磅事件（涨停 / 跌停 / 陷阱三选一），保证稀缺性。

## 界面

- 深色富途风格，K 线图居中，**红涨绿跌**（中国习惯）
- 顶栏：股票名 / 现价 / 涨跌幅 / 倒计时；右侧：资产收益面板
- 图下方：新闻栏（快讯滚动）+ 买 10 股 / 卖 10 股 / 全仓 / 清仓
- MA5/MA10 均线、成交量、十字光标 OHLC 提示、WebAudio 合成音效

## 运行

纯静态页面，直接双击 `index.html` 即可，或起本地服务：

```bash
cd stock-master
python3 -m http.server 8080
# 打开 http://localhost:8080
```
