# 📈 炒股达人

纯前端小游戏：模拟炒股 60 秒，体验被庄家诱多、诱空、反复收割的刺激人生。

## 玩法

1. 输入姓名，点击「开始模拟」
2. 右侧 K 线图（SNK-格力士）随时间自动涨跌，一共 1 分钟走完
3. 期间可操作：**买 10 股 / 卖 10 股 / 全仓 / 清仓**
4. 时间结束弹窗结算：收益 + 收益率 + 趣味称号
5. 「上传成绩」保存到本地排行榜，「再来一局」重开

## 庄家逻辑（核心机制）

K 线涨跌不是随机游走，而是由「庄家状态机」驱动：

| 玩家行为 | 庄家反应 |
| --- | --- |
| 小仓买入 | 拉升诱多（目标 +20%），到点出货砸盘 |
| 全仓买入 | 立刻砸盘收割 |
| 拉升中卖出 | 洗盘抖一下继续拉（让你踏空） |
| 下跌中割肉 | 再小跌一下然后反弹（割在地板上） |
| 反弹中追买 | 继续跌（套牢陷阱） |
| 拉到 +20% | 自动转砸盘出货 |

状态机：`normal 震荡 → pump 拉升 → dump 砸盘 → rebound 反弹 → …`，价格由每步 drift + 正态噪声驱动，每秒生成 1 根 K 线（内部 12 子步 + 随机影线）。

## 界面

- 深色富途风格，K 线图居中，**红涨绿跌**（中国习惯）
- K 线图左上角：股票名 SNK-格力士；右侧：资产收益面板
- 图下方：买 10 股 / 卖 10 股 / 全仓 / 清仓
- MA5/MA10 均线、成交量、十字光标 OHLC 提示、WebAudio 合成音效

## 运行

纯静态页面，直接双击 `index.html` 即可，或起本地服务：

```bash
cd stock-master
python3 -m http.server 8080
# 打开 http://localhost:8080
```
